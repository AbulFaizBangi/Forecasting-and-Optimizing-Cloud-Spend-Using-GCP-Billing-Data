This project, “Forecasting and Optimizing Cloud Spend Using GCP Billing Data,” focuses on analyzing cloud billing data to understand spending patterns and predict future cloud costs. The dataset used in this project comes from Kaggle and contains billing records from Google Cloud Platform services.

The goal is to build a simple MLOps pipeline that processes the data, performs analysis, and trains machine learning models to forecast cloud expenses. Over time, the project will also explore cost optimization insights and anomaly detection in cloud spending.

Dataset source: [Kaggle GCP Cloud Billing Data dataset](https://www.kaggle.com/datasets/sairamn19/gcp-cloud-billing-data).
